# Facility Decision Evidence Promotion Boundary

RC3.6A separates **candidate discovery** from **clinical or scientific admission**.

A source title on the official Joint Trauma System CPG index establishes only a discovery candidate. It does not establish an exact supporting span, applicability to this receiving-clinic case, supersession clearance, contradiction clearance, provider scope, treatment eligibility, or an independently verified clinical rule.

## Claim promotion

Claims may move only through the declared sequence:

`DISCOVERED → IDENTITY_VERIFIED → SPAN_BOUND → APPLICABILITY_REVIEWED → CONTRADICTION_CLEARED → SUPERSESSION_CLEARED → INDEPENDENTLY_ATTESTED → ADMITTED`

Skipping a state, self-attesting, or changing an admission bit does not activate a rule. RC3.6A contains no admitted concrete treatment.

## Calibration promotion

Operational parameters may move only through:

`EXERCISE_ASSUMPTION → DATASET_BOUND → MODEL_FIT → HOLDOUT_PASSED → UNCERTAINTY_BOUND → DRIFT_RULE_DEFINED → CALIBRATED`

The model-family names in the registry are candidate analysis families, not fitted distributions. Current values remain deterministic exercise assumptions.
